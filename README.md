# 🎮 Python Mini Games Collection

A fun collection of beginner-friendly Python games built for practicing programming fundamentals and problem-solving skills.
This repository includes interactive command-line games with simple logic and clean Python code.

---

# 🕹️ Games Included

## 1️⃣ Rock Paper Scissors

Play the classic Rock 🪨, Paper 📃, Scissors ✂️ game against the computer with emoji support and continuous gameplay.

### ✨ Features

* Random computer moves
* Emoji-based interface
* Win/Lose/Tie detection
* Input validation
* Replay option

---

## 2️⃣ Number Guessing Game

Guess the randomly generated number with hints like “Too High” or “Too Low”.

### ✨ Features

* Random number generation
* Hint system
* Multiple attempts
* Beginner-friendly gameplay
